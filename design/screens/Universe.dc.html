▸ How the screen works
  • A symbol drops out only after failing the screen on 3 trading days in a row. Until then it shows "eligible · 1 fail" or "2 fails".
  • Each cycle, held positions get a model call first. Candidates that pass the rules follow in rank order, up to 10 calls, sent at the same time. The rest are stored as no_call (call cap).
  • Rank is the return over the last 20 sessions minus SPY's, recomputed at the daily screen.
  • The company name under each symbol is what code uses to mark headlines as about the symbol. It comes from Alpaca's asset name; universe.names in config overrides it.
